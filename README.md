# La casa que aprendió mi nombre

Cuento original de horror cósmico creado para probar Duvarret: 12 escenas, dos finales, novela visual, linterna, inventario, ganzúas y audio espacial.

[Jugar en GitHub Pages](https://jackThend.github.io/Duvarret/). Activa el sonido y desplázate para alcanzar las marcas.

Esta rama contiene únicamente la exportación web del cuento. El código del Studio está en main. [Créditos y fuentes de los ambientes CC0](CREDITOS.md). Voces nuevas generadas localmente con Kokoro; música, foley e ilustraciones SVG originales; cubierta generada para esta obra. No contiene claves ni el motor de voz.
